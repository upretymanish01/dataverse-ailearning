# ailearning

A shared notebook of Markdown notes about learning and working with AI.

## How we work

1. Every new note is a `.md` file in this repo.
2. Before a note is committed, we read it through together and agree on its content.
3. Once it's agreed, we commit it and put it to use: as a reference, a prompt, a skill or a checklist.
4. When a note turns out to be wrong or out of date, we update it rather than adding a duplicate.

## Layout

| Folder   | What goes there                                     |
|----------|-----------------------------------------------------|
| `notes/` | Concepts, explanations and things we've learned     |
| `guides/`| Step-by-step how-tos we actually follow             |
| `skills/`| Claude Code skills and reusable prompts             |
